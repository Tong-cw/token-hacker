### Instagram (8 张 + Story)

**Carousel 系列每张都需要单独设计。这里给出设计方向：**

**Carousel 1 — 价格 Destroyer (6 slides)**
- Slide 1: 大字标题 + 破碎的价格标签动画感
- Slide 2-4: 左右对比布局，官方价红色/灰色，TH 价绿色
- Slide 5: 图标列表（Bulk buy、Volume discount、One key）
- Slide 6: 大 CTA，单色背景

**Carousel 2 — One Key (7 slides)**
- Slide 1: 金色大钥匙居中，5 个彩色小钥匙环绕
- Slide 2: 混乱的 API key 卡片飞散效果
- Slide 3: 一个钥匙 + 模型 logo 光环
- Slide 4-5: 网格布局 + 代码编辑器 mockup
- Slide 6: 两个支付图标并排
- Slide 7: CTA

**Carousel 3 — 5-Min Migration (7 slides)**
- Step 风格的视觉引导
- 代码块用IDE深色主题渲染
- Python + Node.js 分两屏展示

**Carousel 4 — Model Guide (6 slides)**
- 每屏一个场景类型，大图标 + 简洁文字
- 排名用 🥇🥈🥉 表情符号

**Single Posts (2 张)**
1. 🔒 隐私声明 — 锁图标 + 4 条声明列表
2. 🌍 全球可用 — 世界地图 + 中国/香港亮点

**Story 模板 (5 个)**
- 统一背景色 #0A0A0A
- 大号文字 + emoji
- Swipe up 链接箭头
